The method

Collaboration is a skill. Slop is a one-prompt.

I am not interested in pretending a model wrote my book, or that I never used one. I used several, for six years, on purpose. The interesting part is not that AI got better. It is that the job of the human changed: from memory-keeper, to editor in the margin, to someone who builds a file the model can retrieve, to someone who grades the session and walks when the files do not get read.

“There is skill when you use AI properly. It takes collaboration — not just one single prompt, but a shaping and molding of the data into something beautiful.”

How to do this without producing slop

  1. 01

    Do not let it think for you

    If you are afraid of AI controlling people, stop handing it the thinking. Grow with it. The plot turns, the voice split, the decision to open on a burning city — those are mine.

  2. 02

    Keep a bible the model can read

    A 23-chapter reincarnation epic will not fit in a prompt. Book2Data exists because I got tired of characters forgetting they had died.

  3. 03

    Lock the voices

    Jack is crude inside and forced-Arthurian outside. Zahilla is mythic. Fang is sarcastic. Models flatten that.

  4. 04

    Grade the session. Switch tools.

    A 6/10 is useful. A 4/10 on the documents is a stop. I have ended Grok sessions and moved to Copilot in the same afternoon.

  5. 05

    Shape, don't one-shot

    Anyone can produce slop from a single prompt. Collaboration is a loop.

  6. 06

    Use the same method on the software

    The karaoke reader and this site were built the same way as the novel. New tools. Same director.

The tools changed. The argument did not.

  1. 2020–2021

    Early public models

    Chat windows that forget

    Context windows were tiny. Characters forgot their own deaths. I kept bibles in Word. Writing with AI meant being the memory the model did not have.

  2. 2022–2023

    Microsoft Copilot

    Copilot in the document

    Less reciting lore, more fighting over a line. When Grok later failed a file-read, I moved the session to Copilot. That is not brand loyalty. That is the job.

  3. 2023–2025

    RAG / document reading

    The notes file is the real invention

    Book2Data is characters, artifacts, voice rules, and a running grade of the session. If the model cannot hold Fang, Adel, and Zahilla at the same time, you have a slot machine.

  4. 2025–2026

    Grok, Copilot, then agents

    Grok as scene partner — and a scorecard

    File reading 4/10. Session terminated early, moving to Copilot. Then agents showed up. I keep the story. The tool proposes. I send it back.
